Incident INC-001 · Recorded outputs and evaluation results

1. Evidence ingestion 50 normalized events and 50 timeline events recorded. Evidence sources include proxy and application logs, container metadata, network captures and configuration artifacts.
2. Graph and GNN 30 graph nodes and 24 edges. Held-out test n=12: precision 1.000, recall 0.7778, F1 0.875, accuracy 0.8333. Results are preliminary and use scenario-intent labels.
3. Incident reconstruction Two SQL-injection-shaped requests were observed about 1 ms apart. Their relationship remains a candidate correlation. Database access and exfiltration were not independently verified.
4. LLM narrative Narrative synthesis output is recorded. Validation checks evidence references and limits unsupported root-cause confirmation; this does not prove every generated statement is true.
5. Security knowledge / RAG FTS5 BM25 retrieval; 10 unique CAPEC/CWE references recorded for the example incident. Retrieved material supports analysis and recommendations, not proof of exploitation.
6. Remediation planning Remediation recommendations are advisory. A recommendation alone does not establish that a change was applied or that it was effective.
7. Penetration testing / validation Controlled validation outcome is not established in this report. The recorded scenario observed Nginx-to-API forwarding and an HTTP response; downstream database activity remains unverified.
8. Judge Agent Pending recorded decision. No PASS/FAIL outcome is claimed without a supporting execution artifact.
9. SHAP explainability For scenario_011, raw GCN edge logit ≈ 40.1342 and baseline ≈ −2.9315. Largest positive contributions include HTTP feature IDs 21, 18 and 6. Reconstruction error ≈ 7.11 × 10⁻¹⁵. The logit is not a calibrated probability.
10. Bayesian Neural Network 500 posterior samples; 12 held-out test edges. Accuracy 0.8333, precision 1.000, recall 0.7778, F1 0.875, Brier score 0.0712 and MAE 0.2173. This predicts attack-edge-label proxy scores, not validated post-remediation residual risk.
11. BNN limitations The held-out set is small (n=12). Predictive intervals and prototype risk bands are not empirically calibrated for operational residual-risk decisions.
